# 本地知识检索与 Profile

## 技能与执行环境

检查实际处理飞书消息的 Profile 是否发现本 Skill、能否执行终端与读取文件、执行后端能否访问授权知识目录。

需要部署时，将本 Skill 的完整目录（包括 `scripts`、`references`）放入当前安装支持的技能目录。确认 Profile 的技能发现规则；若使用正式支持的路由，查阅当前版本文档，不虚构路由字段。不要为一个会话切换整个 Gateway 并影响其他用户。

同名技能存在时比较并备份后更新。刷新技能列表或用适用的新会话验证，仅在当前版本确实需要时重启。

## 检索方法

优先用户已有的分层知识结构：卡片 → 主题摘要 → 索引 → 导入正文 → 原始文件。目录名称由用户实际知识库决定，不要求重组资料。

附带脚本依赖 Python 3.9+ 标准库，搜索指定根目录内的 UTF-8 Markdown 文件，不需要数据库、云接口或第三方 Python 包。执行前将下面占位符替换为确认后的本地路径：

```powershell
$skillRoot = '<SKILL_ROOT>'
$knowledgeRoot = '<AUTHORIZED_KNOWLEDGE_ROOT>'
python -X utf8 (Join-Path $skillRoot 'scripts\search_knowledge.py') --root $knowledgeRoot --query '示例主题' --limit 5
```

每次将 root 指向当前需要的层级目录。查询是固定字符串匹配，多个概念分别搜索，不将长句无匹配等同于没有相关知识。脚本跳过符号链接与目录联接，输出根目录相对路径、行号及片段；不发送网络请求，不写知识库。输出条数上限不等于扫描文件数上限。

脚本发生读取失败时返回非零退出码并列出相对路径错误，不能把部分读取结果当作完整检索。知识库不存在时也必须报告错误，不能报告“无匹配”。

搜索结果用于定位，随后读取命中文件相关章节。索引仅用于导航；`index_only`、`failed` 或转换错误的资料不能充当正文证据。按 `source_path` 跟进原件前，确认其位于授权访问范围。

把用户输入作为参数值传递，不能拼接为可执行代码。中文异常时检查文件与终端编码，不自动改写源文件。

## 回答

先给结论，再给依据及来源，语言按用户要求。关键事实对应实际读取的章节，区分文档原意和推断。默认来源格式为“文档标题 + 知识库相对路径 + 章节”，避免泄露设备用户名和目录结构。不要承诺手机能打开本机路径。

示例仅展示格式，不代表真实业务资料：

```text
结论：该示例流程适用于指定的演练场景。
依据：文档“适用范围”章节列出了演练条件。
来源：示例流程文档；cards/example-process.md；适用范围。
```

资料不足时报告已查层级及缺口。当前政策、合同、法律或资费等事实须核对权威来源，不能把旧笔记当作当前口径。

## 验收与回滚

本地：依赖可用 → 命中已知测试文档 → 读取正文 → 答案可追溯。

飞书：用户发送约定问题或授权代理发送 → 实际会话调用检索和读取工具 → 同一会话收到带来源回答。复述示例不算真实检索。

此发布包不含任何部署环境的连接验收结论。部署后单独记录已验收及未验收层级。需回滚时仅恢复本轮配置与技能改动，不删除知识资料或聊天历史。
